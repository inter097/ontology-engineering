# El libro

Copia local del libro que sigue este repositorio, para poder citarlo sin depender
de la red y sin releer versiones de terceros que renumeran las secciones.

- `OEbook.pdf` — el libro tal cual lo publica la autora.
- `OEbook.txt` — el mismo, extraído con `pdftotext -layout`, para poder hacer
  `grep` de secciones y enunciados de ejercicios.

## Cita

> **Keet, C. Maria.** *An Introduction to Ontology Engineering*, v1.5. 2020.
> <https://people.cs.uct.ac.za/~mkeet/OEbook/>

## Por qué está aquí y no se usa LibreTexts

La edición de LibreTexts **inserta una sección «Prelude» al principio de cada
capítulo** y cuenta *«How to Use the Book»* como capítulo 1. Resultado: tanto la
numeración de capítulos como la de secciones aparecen corridas **+1** respecto al
original.

Las citas de este repositorio usan la numeración de la autora, que es la de este
PDF. Índice real:

| Cap. | Título |
|---|---|
| 1 | Introduction |
| 2 | First order logic and automated reasoning in a nutshell |
| 3 | Description Logics |
| 4 | The Web Ontology Language OWL 2 |
| 5 | Methods and Methodologies |
| 6 | Top-down Ontology Development |
| 7 | Bottom-up Ontology Development |
| 8 | Ontology-Based Data Access |
| 9 | Ontologies and natural languages |
| 10 | Advanced Modelling with Additional Language Features |
| 11 | Ontology modularisation |

Los ejercicios del libro vienen en dos series por capítulo, y conviene no
confundirlas al citar: **«Review question N.x»** (conceptuales) y **«Exercise
N.x»** (prácticos).
